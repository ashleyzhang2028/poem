# 东周诸侯（春秋战国）· 253 位

> Issue #407 的第三次追问：
> 「需要补齐东周后期 春秋战国各主要诸侯国诸侯王的世系及数据 正确按时间排序」

## 一、这一段为什么另立

卷里原有「东周（春秋）」「东周（战国）」两段，那两段是**周天子**（平王 →
赧王，25 位）。诸侯与天子混进同一段，等于把两类人摆成一列：谱系、纪年、
称号全乱。所以诸侯**另立一段**「东周·诸侯（春秋战国）」，排在两段天子之后、
「秦」之前 —— 段序上仍然按时间走，这也是用户说的「正确按时间排序」里
最要紧的一层。

  他们是**晋国的卿**，不是诸侯。只在晋国那一段的相关正文与「东周（战国）」
  的叙事里出现，不在这里另立一条（否则「同一人两处」）；
- **诸侯之下的卿大夫**（管仲、子产、晏婴、伍子胥、范蠡……）—— 他们不是君主。
  管仲、子产、晏婴在**历代名家**卷；伍子胥、范蠡、孙武、商鞅、李斯等同理；
- **小国**（陈、蔡、曹、滕、薛、莒、邾、许、卫……）—— 史书里有世系的都收得下，
  但用户说的是「**主要**诸侯国」，收全则这一段会从 253 位膨胀到上千位，
  而其中多数君主只有一句记载。取舍的尺子是**春秋五霸与战国七雄的所在国**，
  加上吴越（霸业的当事人）与宋鲁郑（中原的枢纽与礼乐之邦）。

## 三、每位长什么样

```
┌──────┬──────┐
│ 皇号 │ 晋文公（晋）
│ 世系 │ 晋穆侯（…） → 晋殇叔（…） → … → 晋静公（…）   ← 一国一条
│ 姓名 │ 姬重耳
│ 年号 │ —（晋侯纪年）
│ 在位 │ 前 636—前 628，9 年
│ 谥号 │ 文公
│ 庙号 │ —（不立庙）
│ 谱系 │ 晋献公之子；子晋襄公继位
└──────┴──────┘

【生平】

【政治】

【经济】

【军事】

【文化】

【民族外交】

【个人】

【一句话】
```

九段**每段之间空一行**（正文是词条式的长段，挤在一起分不出眉眼；
阅读器把空行渲染成一次换行）。表格与【生平】之间也留一行，不贴在框线上。

与全卷比，诸侯多了一格 **「世系」**：它是**一国一条**的世系图，按在位先后
把这一国的君主连起来。第七格「谱系」是**一位一条**（承谁之统、传与谁），
两者互为表里 —— 一格看一个人在链条上的位置，一格看整条链。

**年号与庙号如实标「无」**：年号起于汉武帝建元，春秋战国没有年号，一律写
本国纪年（「晋侯纪年」「楚君纪年」）；庙号之制是汉以来的事，诸侯全填
「—（不立庙）」。谥号则照写 —— 春秋战国的国君大多有谥，无谥的如实标出
（「—（被杀，无谥）」「—（亡国，无谥）」）。

## 四、白话译文（只有这一段有）

这 253 位各附一篇**列传体**的白话：一段话写完一位君主 —— 他是谁、
在位多少年、做过哪几件要紧事、怎么死的、传给了谁。事实取自《史记》
十二诸侯年表与各国世家、《左传》《国语》《战国策》的通说。

为什么不做逐句对译：帝王卷的「正文」不是古文原文，而是照《史记》世家与
《左传》的成句转写成的史实叙述；再逐句译一遍就是同义反复。写成一段小传，
**一国的译文连着读就是一部小型的世家** —— 这也正是用户说的「世系及数据」
里「世系」那一层的意思。

译文与正文一样收在 `data/text-master.js`（唯一一份），壳里只留一个
`hasTranslation` 标记。**一处必须留心的接线**：`js/reader-core.js` 原先
按「整部带不带译文」算列表行上的「待补」标记，而帝王卷整部是词条式 ——
若整卷都算「不带译文」，这 253 行的译文入口就显不出来；若整卷都算「带译文」，
其余几位又会各挂一个空的「待补」。所以新增了一个可选的 `CFG.hasTranslation`
谓词，把口径从「整部」改成「按条」；没给这个谓词的集子行为与从前一字不差。

## 五、号段：又是那条纪律

诸侯段排在「东周（战国）」之后、「秦」之前，是**后补的段**却是**中间的位置**。
壳里的 id 按列表次序生成，而主表 `data/text-master.js` 拿 id 当「同一人」的
钥匙 —— 照位次编号会把「秦」以后那两百多位的 id 整体推后一位，正文全串门
（名著导读那一卷踩过、上一轮的传说时代也差点踩）。

所以诸侯段**另起号段** `em-c-vassal-01…253`，老号段 `em-c-01…340` 与
`em-c-legend-01…16` 一位不动。核验办法：

```bash
node scripts/build-emperor.js          # 出壳
diff <(git show HEAD:data/poems-emperor-cn.js | grep -o 'id: "em-c-[0-9]*"') \
     <(grep -o 'id: "em-c-[0-9]*"' data/poems-emperor-cn.js)   # 应当无输出
```

`test/dwang.test.js` 里也有对应的断言守着（「其余各段仍在老号段 em-c-NN
（一位不动）」）。

## 六、一处踩过的坑：世系图只在第一条上

世系图按国别取。第一版写成：

```js
CN.forEach(function (r) {
  if (r.period !== VASSAL_GROUP) return;
  r.country = r.dynastyLabel;              // ← 边标边算
  r.lineageChart = lineageOf(CN, r.country);
});
```

算到第一条时，**后面的条目还没有 `country`**，`lineageOf` 只捕到当前这一条 ——
世系图退化成一个人。必须分两步：先全部标上国别，再算图。
