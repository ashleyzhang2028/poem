# 📖 古诗词背诵 · 艾宾浩斯记忆曲线

面向小朋友的**古诗文复习与背诵**应用。覆盖**小学一年级到高中三年级**（人教/统编版教材）共 **242 首**古诗文。

纯前端单页应用，**打开即用、无需联网、无需注册**，所有学习进度保存在手机/电脑本机浏览器里。

## ✨ 核心功能

### 1. 选择当前年级 + 上下学期
- 顶部按「小学 / 初中 / 高中」分学段，再选具体年级
- 一键切换「上学期 / 下学期」，只看当前进度对应的教材内容

### 2. 每日 5 首背诵任务（可调 3/5/8/10 首）
每次进入应用，自动列出**今天要背的诗词名称**（默认 5 首）：

- 🟠 **复习** —— 按记忆曲线到期、今天必须回顾的诗
- 🟢 **新学** —— 还没学过的诗，逐首补齐

不点击就只是"今天要背这 5 首"的清单；**点击某一首**才会展开：

- 诗题
- **作者**
- **朝代**
- 完整正文（保留原文换行、宋体展示，适合跟读）

### 3. 艾宾浩斯遗忘曲线自动排期
点开诗词后，如实选择自己的掌握程度，系统自动算出下次复习时间：

| 选择 | 效果 |
|---|---|
| 😄 记住 | 升级到下一记忆阶段，间隔翻倍 |
| 🤔 模糊 | 停留当前阶段，**12 小时**后再复习 |
| 😵 忘记 | 降级一级，**30 分钟**后立刻重来 |

复习间隔序列（天）：

```
当天 → 1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 → 240
```

规律即"先密后疏"：刚记住时反复得快，越牢固间隔越长，用最少次数把诗记进长期记忆。

### 4. 进度可视化
- 今日环形进度（已完成 / 总数）
- 每首诗的记忆阶段与掌握度进度条
- 「本年级全部诗词」折叠面板：本学期诗词数 / 已学 / 较牢固 / 待复习

### 5. 数据管理
- 导出备份（JSON 文件，可换设备导入）
- 导入备份
- 清空进度

## 🚀 使用方法

### 方式一：直接打开
用浏览器打开根目录的 `index.html` 即可。

### 方式二：本地起服务（推荐，避免个别浏览器 file:// 限制）
```bash
# Python 3
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

### 方式三：手机上使用
把 `index.html` 及 `css/`、`js/`、`data/` 目录一起放到任意静态服务器（GitHub Pages / CNB Pages / Nginx 均可）。
在手机浏览器打开后，可"添加到主屏幕"，像 App 一样使用。

## 🔧 扩展数据

在 `data/poems-N.js` 中按以下结构追加即可，`id` 需唯一：

```js
{
  id: "xx1-13",
  title: "诗题",
  author: "作者",
  dynasty: "唐",
  grade: 1,      // 1-12
  term: 1,       // 1 上学期 / 2 下学期
  text: "第一句，\n第二句。"
}
```

## 💡 设计说明

- **为什么要"不点击就只显示诗名"**：先给孩子回忆的机会，避免直接看到正文产生依赖，符合"主动回忆"的记忆原理。
- **为什么要如实评价掌握程度**：记忆曲线的排期完全依赖真实反馈。忘记却选"记住"，会导致间隔拉得过长而彻底遗忘。
- **为什么跨年级复习**：已经学过的诗即使升了年级也要按期复习，因此到期诗会在任意年级的任务列表中出现，保证不遗忘。
