# 📖 Ashley 背古诗词 · 艾宾浩斯记忆曲线

面向小朋友的**古诗文复习与背诵**应用。覆盖**小学一年级到高中三年级**（人教/统编版教材）共 **242 首**古诗文。

纯前端单页应用（PWA），**打开即用、无需注册、可离线**，所有学习进度保存在手机/电脑本机浏览器里。

支持**电脑、安卓手机、苹果手机（iPhone / iPad）**；苹果手机上可通过 Safari「添加到主屏幕」当独立 App 使用。

## ✨ 核心功能

### 1. 在设置里选择年级 + 学期
- 年级/学期选择收进右上角 ⚙️ 设置弹层，首页不再常驻显示
- 设置内按「小学 / 初中 / 高中」分学段，再选具体年级
- 一键切换「上学期 / 下学期」，只看当前进度对应的教材内容

### 2. 每日 5 首背诵任务（可调 3/5/8/10 首）
每次进入应用，自动列出**今天要背的诗词名称**（默认 5 首）：

- 🟠 **复习** —— 按记忆曲线到期、今天必须回顾的诗
- 🟢 **新学** —— 还没学过的诗，逐首补齐

不点击就只是"今天要背这 5 首"的清单；**点击某一首**才会展开：

- 诗题
- **作者**
- **朝代**
- 完整正文（保留原文换行、宋体展示，适合跟读）

### 3. 艾宾浩斯遗忘曲线自动排期
点开诗词后，如实选择自己的掌握程度，系统自动算出下次复习时间：

| 选择 | 效果 |
|---|---|
| 😄 记住 | 升级到下一记忆阶段，间隔翻倍 |
| 🤔 模糊 | 停留当前阶段，**12 小时**后再复习 |
| 😵 忘记 | 降级一级，**30 分钟**后立刻重来 |

复习间隔序列（天）：

```
当天 → 1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 → 240
```

规律即"先密后疏"：刚记住时反复得快，越牢固间隔越长，用最少次数把诗记进长期记忆。

### 4. 进度可视化
- 今日环形进度（已完成 / 总数）
- 每首诗的记忆阶段与掌握度进度条
- 「本年级全部诗词」折叠面板：本学期诗词数 / 已学 / 较牢固 / 待复习

### 5. 数据管理
- 导出备份（JSON 文件，可换设备导入）
- 导入备份
- 清空进度

## 🚀 使用方法

### 方式一：直接打开
用浏览器打开根目录的 `index.html` 即可。

### 方式二：本地起服务（推荐，避免个别浏览器 file:// 限制）
```bash
# Python 3
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

### 方式三：手机上使用

把整个目录放到任意静态服务器（GitHub Pages / CNB Pages / Nginx 均可），用手机浏览器打开即可。
应用已内置 PWA 能力，**安装到桌面后可以离线背诵**（首次打开需联网加载一次）。

#### 🍎 苹果手机 / iPad（iPhone / iPadOS）

iOS 不会弹「安装」按钮，需要手动添加到主屏幕，步骤：

1. 必须用 **Safari** 打开应用地址
   （微信 / QQ / 钉钉等 App 内置浏览器都不支持「添加到主屏幕」，应用会自动提示您改用 Safari）
2. 点屏幕**底部中间的「分享」按钮**（方框 + 向上箭头 ⬆️）
3. 在弹出的菜单中向下滑动，选择 **「添加到主屏幕」**
4. 右上角点 **「添加」**

完成后桌面会出现「古诗词背诵」图标，点开即为**全屏运行**，没有 Safari 地址栏和工具栏，体验与原生 App 一致。

针对 iOS 已做的适配：

| 项目 | 说明 |
|---|---|
| `apple-mobile-web-app-capable` | 从主屏幕启动时全屏运行，不显示浏览器界面 |
| `apple-mobile-web-app-status-bar-style` | 状态栏样式适配，内容不被状态栏遮挡 |
| `apple-touch-icon` ×4 | 提供 120 / 152 / 167 / 180 四种尺寸，覆盖 iPhone、iPad、iPad Pro，图标清晰不模糊 |
| `viewport-fit=cover` + `env(safe-area-inset-*)` | 适配刘海屏、灵动岛与底部横条，内容不被遮挡 |
| Service Worker | 首次打开后缓存全部资源，**断网也能正常背诵** |
| 输入框 16px | 避免 iOS 聚焦输入框时页面自动放大 |
| 弹层避让 | 弹层打开时自动隐藏安装引导条，不会挡住操作按钮 |

#### 🤖 安卓手机

用 Chrome / Edge 打开，浏览器若支持会提示「安装应用」；也可在菜单中选择「添加到主屏幕」。

#### 💻 电脑

浏览器直接打开即可；也可在浏览器地址栏右侧点安装图标，装成独立窗口应用。

## 🧪 测试

```bash
bash test/run.sh      # 全部测试
npm test              # 同上
```

包含三部分：

| 测试 | 内容 |
|---|---|
| `test/scheduler.test.js` | 记忆曲线调度算法断言（间隔序列、升降级、模糊、跨年级复习、持久化等） |
| `test/ui.test.js` | jsdom 模拟浏览器的端到端断言（年级/学期切换、5 首计划、点击展开、评价后进度更新等） |
| `test/pwa.test.js` | **真实浏览器**校验 iOS / PWA 能力（见下） |

关于 PWA 测试：

- 需要真实浏览器，依赖 `puppeteer`；未安装时自动跳过，不影响其它测试
- 覆盖 iPhone Safari、iPad、微信内置浏览器、安卓 Chrome、桌面 Chrome 五种环境
- 校验 iOS meta 标签、四种 `apple-touch-icon` 尺寸是否可访问、Service Worker 注册、**断网后可打开**、引导条按平台正确显示、弹层按钮是否被遮挡等共 27 项

单独运行（需先起服务）：

```bash
npm i -D puppeteer
node scripts/serve.js &
node test/pwa.test.js
```

  title: "诗题",
  author: "作者",

## 💡 设计说明

- **为什么要"不点击就只显示诗名"**：先给孩子回忆的机会，避免直接看到正文产生依赖，符合"主动回忆"的记忆原理。
- **为什么要如实评价掌握程度**：记忆曲线的排期完全依赖真实反馈。忘记却选"记住"，会导致间隔拉得过长而彻底遗忘。
- **为什么跨年级复习**：已经学过的诗即使升了年级也要按期复习，因此到期诗会在任意年级的任务列表中出现，保证不遗忘。

## 🔒 关于数据与隐私

- 所有学习进度只存在**本机浏览器**（localStorage），不上传任何服务器
- 无账号、无埋点、无第三方请求，断网可用
- 想在手机和电脑之间同步，可用设置里的「导出备份 / 导入备份」
